# DOSSIER（模块档案）

> 每个会被**子任务独立改动**的深改目标模块，配一份"现场事实"档案：子任务只吃派发单 + 这份档案就能开工，不必全仓探索。档案只写**当前事实**（怎么写、怎么防错、已知坑），不写演变过程；失效内容直接改写。
> 当前目录暂无具体档案（模块现状见 `MODULE_REGISTER.md`，操作通道与坑见 `.agents/skills/exceldiff-workflow/SKILL.md`）；第一个需要深改的模块按下面骨架建档。

## 一份档案写什么（建议骨架）

```markdown
# <模块名> 档案

> 引用约定：`ADR-###` = DECISION_LOG.md 的决策；`R-###` = RISK_REGISTER.md 的未关闭风险。

## 职责与边界
- <一句话：这个模块管什么、明确不管什么>

## 关键路径（入口锚点）
- 路径/File.cs <!-- anchor:锚点ID --> —— <一句话说明这个入口是干什么的>

## 数据流（用可见对象讲）
- <用户操作 → 系统行为 → 可见结果；参数从哪来>

## 已知坑
- <一句话一条：现象、根因、规避方式>

## 相关决策与风险
- <ADR-### / R-### 列表，各带一句人话>
```

## 用法纪律

- 派发省档子任务时，把档案中与本单相关的**事实摘要**（≤3KB）内联进派发单 §C；只有对该模块深改、摘要承载不了语义时才让子任务整读档案。
- 档案不是第二个台账：进度/状态写 `PROJECT_STATUS.md`，档案只放"较稳的现场事实"。
